Shop.TZ E-Commerce Showcase

A premium fashion e-commerce storefront designed and developed by **Mwijay Davie** (Tanzania). Features clean responsive layouts, Montserrat typography, and an integrated **AI Personal Stylist Chatbot** with multi-key API rotation and Vercel Serverless security. Updated to 2026.

Core Layout Pages:

  1. Home Storefront
  2. Product Details (Graphic T-Shirt)
  3. Category Filter Page
  4. Shopping Cart
  5. Checkout Page
  6. Order Success / Confirmation
  7. AI Wardrobe Stylist Room (Interactive Canvas!) ⚡

Interactive AI Stylist

Click the floating button in the bottom right corner of any page to open the Personal Stylist chatbot helper!
